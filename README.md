# Pomodoro Timer (Windows Desktop) 🍅

تطبيق مكتبي خفيف وسريع لنظام ويندوز يهدف إلى تحسين الإنتاجية وتتبع ساعات العمل والتركيز عبر تقنية بومودورو القياسية.

---

## ✨ المميزات الرئيسية
- ⏱️ **مؤقت بومودورو القياسي:** فترات تركيز مع استراحات قصيرة وطويلة قابلة للتخصيص.
- 🔕 **يعمل بدون إنترنت (100% Offline):** خصوصية تامة؛ جميع بياناتك وسجلاتك تُحفظ على جهازك محلياً دون أي خوادم خارجية.
- 🔔 **تنبيهات ويندوز وإشعارات صوتية:** إشعارات مرئية وصوتية تنبهك عند انتهاء وقت الجلسة أو بدء الاستراحة.
- 📌 **التكامل مع شريط المهام (System Tray):** تشغيل التطبيق في الخلفية وتصغيره لمنطقة الإشعارات لتوفير مساحة العمل.
- 📊 **سجل الجلسات المحلي:** متابعة عدد جلسات العمل وساعات التركيز اليومية.

---

## 🛠️ التقنيات المستخدمة
- **اللغة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose Multiplatform (Desktop JVM) + Material 3
- **إدارة الحالة:** Kotlin Coroutines & StateFlow
- **التخزين المحلي:** kotlinx.serialization (JSON)

---

## 🚀 كيفية التشغيل والتجربة

### المتطلبات المسبقة:
- نظام تشغيل **Windows 10 / 11**.
- تثبيت **JDK 17+**.

### خطوات التشغيل:
1. استنساخ أو فتح مجلد المشروع:
   ```bash
   cd C:\Users\19\Dev\pomodoro-timer
   ```
2. تشغيل التطبيق محلياً عبر Gradle:
   ```bash
   .\gradlew.bat run
   ```
3. تحزيم التطبيق وتوليد ملف تثبيت ويندوز (`.msi` / `.exe`):
   ```bash
   .\gradlew.bat packageDistributionForCurrentOS
   ```
